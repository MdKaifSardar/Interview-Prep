## 🎯 Master Sheet Format Standard

Every topic module in this repository follows a standardized 4-part answer framework:
1. **TL;DR:** 1–2 sentence summary for rapid recall & emergency skims.
2. **💡 Core Concept & Explanation:** Intuitive breakdown of *why* and *how* the underlying mechanism works.
3. **🛠️ Code / Visual Diagram / Table:** Working query, code snippet, ASCII flow, or comparative table.
4. **⚠️ Interview Pitfall / Pro-Tip:** Real-world edge cases, performance traps, and common interviewer follow-ups.
